Mis Proyectos Destacados

📱 Aplicación Móvil: Gestión de Tareas Escolares

Fecha: 05 de junio de 2025

¿Qué es? Es una aplicación para teléfonos diseñada para ayudar a los estudiantes a organizar sus tareas, proyectos y fechas de entrega. Cuenta con un calendario, recordatorios automáticos y un sistema para ver el avance de cada actividad. Su objetivo es facilitar la organización personal, mejorar el cumplimiento de las tareas y reducir el estrés académico.

Lo que aprendí: A identificar problemas reales, pensar soluciones útiles, definir metas claras y planificar todo el desarrollo de una idea desde cero.

🍪 Sistema de Inventario — Repostería "CookieBrown"

Programa en C++ para gestionar productos, existencias y movimientos de una repostería. Aplica clases, herencia, polimorfismo, encapsulamiento y memoria dinámica. Incluye menú interactivo, búsqueda, altas y bajas de productos.

📐 Resolución Numérica de Ecuaciones
